OpenCode

Trabalhe em tarefas de programação com um agente que pode se conectar a provedores de IA ou a um modelo local compatível.

Abrir site oficial ↗Voltar ao catálogo

OpenCode é gratuito?

O software é aberto, mas o modelo conectado não é automaticamente gratuito. Provedores podem exigir conta, assinatura ou chave de API. A integração com Ollama local exige instalação e recursos próprios. Não há instalação automática pelo T.Free.

O acesso descrito não é garantia de uso ilimitado. Confira a disponibilidade e as regras atuais no provedor antes de começar.

Como avaliar na prática

Use uma tarefa pequena e verificável. Leia o código sugerido, rode testes e examine as dependências antes de integrar ao projeto.

O que observar antes de usar

Editor, extensão e modelo são componentes diferentes. Um assistente gratuito pode conectar-se a uma API paga.
