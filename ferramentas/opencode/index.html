OpenCode é gratuito?

O software é aberto sob licença MIT e oferece uma seleção de modelos gratuitos, conforme a oferta atual. Outros provedores podem exigir conta, assinatura ou chave de API. Modelos locais exigem recursos próprios. O site informa condições próprias de uso de dados nos modelos gratuitos: confira a política antes de enviar conteúdo sensível. Não há instalação automática pelo T.Free.

O acesso descrito não é garantia de uso ilimitado. Confira a disponibilidade e as regras atuais no provedor antes de começar.

Modelo / API
Há uma seleção de modelos gratuitos oferecida pelo projeto. API, conta ou assinatura externa depende do provedor; também pode usar Ollama local compatível.
Infraestrutura
Exige instalação e configuração do ambiente; modelos locais usam recursos do computador.

Dependências a considerar: Provedor de API/assinatura escolhido ou modelo local · Hardware e energia

Como avaliar na prática

Use uma tarefa pequena e verificável. Leia o código sugerido, rode testes e examine as dependências antes de integrar ao projeto.

O que observar antes de usar

Editor, extensão e modelo são componentes diferentes. Um assistente gratuito pode conectar-se a uma API paga.
